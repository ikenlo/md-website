# Історія версій

## 0.1.0 — 2026-11-05

Перша демо-версія сайту M&D beauty salon.

- Дизайн mobile-first: темно-зелений із золотом, кремові секції; шрифти Tenor Sans + Manrope, логотип — Cormorant Garamond.
- Блоки: головний екран, послуги, про нас, майстри, прайс (ціни за довжиною волосся), онлайн-запис, роботи, сертифікати, відгуки, FAQ, контакти з картою.
- Онлайн-запис у 4 кроки (послуга → майстер → дата і час → контакти), запис до конкретного майстра, вибір довжини волосся.
- Sticky-кнопка «Записатись онлайн» на телефоні та планшеті.
- Інтеграція з MDs connect через серверний проксі (токен лише на сервері); контракт API — `docs/API.md`.
- Працює в демо-режимі (`mode: "mock"`) з тестовими даними.

Ще не готово: реальне підключення до MDs connect, фото послуг, справжні дані салону (адреса, ціни, майстри, відгуки).
